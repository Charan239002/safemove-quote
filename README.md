# Moving Cost Estimator

A full-stack web app that gives customers an instant estimate for their move. I built it to get hands-on experience with React, FastAPI, and connecting a frontend to a REST API.

## What it does

- Customer picks a home size, enters the distance, and chooses whether they want packing
- The React frontend sends the details to a FastAPI backend
- The backend validates the input, calculates the price, and sends back the estimate
- Clear error messages for bad input or when the server is unreachable

## Tech stack

- **Frontend:** React (Vite), JavaScript (ES6+), CSS
- **Backend:** Python, FastAPI, Pydantic
- **Tools:** Git, GitHub, ESLint, VS Code

## How the pricing works

- Base price by home size (Studio $400, 1 Bed $700, 2 Bed $1,100, 3 Bed $1,600)
- Plus $1.50 per mile
- Packing service adds 30%

Example: 2 bedroom, 25 miles, with packing = (1100 + 37.50) × 1.3 = **$1,478.75**

## API

`POST /quote`

Request:
```json
{
  "home_size": "2-bedroom",
  "miles": 25,
  "packing": true
}
```

Response:
```json
{
  "home_size": "2-bedroom",
  "miles": 25,
  "packing": true,
  "estimate": 1478.75
}
```

Interactive API docs are available at `/docs` (Swagger UI, generated by FastAPI).
